# App Store-materiaal

| Bestand | Inhoud |
|---|---|
| `P2000-Apeldoorn-AppStore-1.0.0-nl.zip` | Nederlandse screenshots (iPhone, iPad, Mac, Apple Watch, Apple TV) + promotional artwork, app-icoon en `App-Store-teksten.md` |
| `P2000-Apeldoorn-AppStore-1.0.0-en.zip` | Engelse screenshots + dezelfde gedeelde bestanden |

De set is in twee zips gesplitst omdat GitHub geen bestanden boven de 100 MB toestaat. Alle afbeeldingen zijn PNG zonder alfakanaal, in de exacte maten van Apple. Uitleg en uploadtabel staan in `App-Store-teksten.md` in elke zip.
